## 📌 Executive Overview

**Brandex** is an end-to-end Technology, Digital Transformation, Business Solutions, and Infrastructure Company founded in 2023 in Vijaynagar, Bangalore, India. 

We engineer high-performance web applications, bespoke enterprise CRM & ERP systems, autonomous AI pipelines, zero-trust cloud setups, and physical IT networking infrastructure for ambitious businesses across India and globally.

### 💎 Core Architectural Pillars
- **100% Source Code Ownership**: Full intellectual property, database schemas, and codebase handover on launch — zero platform lock-in or recurring software tax.
- **Sub-Second Performance**: Global edge deployment, sub-18ms TTFB, and strict Core Web Vitals optimization (sub-50ms INP, LCP < 1.2s).
- **Security-First Paradigm**: Zero-Trust network topologies, encrypted data storage, and compliance with the India DPDP Act and international standards.
- **Unified Ecosystem**: Seamless combination of corporate engineering services, commercial software licenses, community guilds, and collegiate education.

## ⚡ Getting Started

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **Package Manager**: npm (v9+), yarn, or pnpm

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/brandex/brandex-digital-canvas.git
cd brandex-digital-canvas
npm install
```

### 2. Development Mode
Start the Vite development server with Hot Module Replacement (HMR):
```bash
npm run dev
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### 3. Production Build & Static Prerendering
Compile TypeScript, generate the optimized production bundle, prerender static HTML routes, and regenerate `dist/sitemap.xml`:
```bash
npm run build
```

### 4. Local Preview
Preview the production build locally:
```bash
npm run preview
```

### 5. Automated Tests & Type Checks
Run Vitest unit tests and TypeScript strict type-checking:
```bash
npx tsc --noEmit
npm run test
```
